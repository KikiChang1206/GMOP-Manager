# 固定取件機器人 — 操作手冊

> 這套系統讓「固定取件」的客戶**填一次、長期生效**;每天早上系統會自動把當天該取件的客戶
> 建入 GoodMaji「代收包裹 → 一般代取」,不用再每天手動下單。

---

## 一、系統總覽

| 部分 | 用途 | 網址 / 位置 |
|---|---|---|
| **前台表單** | 給同事/客戶填「固定取件」設定 | `http://202.182.99.181:3000/` |
| **後台** | 看客戶清單、執行記錄、新增/暫停/刪除 | `http://202.182.99.181:3000/admin` |
| **建單機器人** | 每天 **早上 08:00**(台灣時間)自動建單 | 主機自動執行,不需人工 |

- 後台需要**管理密碼**(當初設定的那組)。
- 機器人建的每一筆,**取件人欄會填「API」**,方便一眼認出是自動建的、需確認實際件數。
- 每筆**包裹數預設 1**,備註會帶入客戶填的叮嚀。

## 二、日常操作(不需要技術背景)

### ✅ 新增一位固定客戶
**方法 A:前台表單**(給客戶或同事填)
1. 打開 `http://202.182.99.181:3000/`
2. 填客戶名稱、取件地址、備貨好時間、取件日(每天或指定星期)、電話、聯絡人、生效日期、備註
3. 送出 → 完成畫面會列出剛填的內容供核對

**方法 B:後台新增**(內部員工用,不必切換網址)
1. 登入後台 → 點上方「**＋ 新增設定**」分頁
2. 填同樣的欄位 → 按「新增設定」→ 會自動跳回客戶清單

> 生效日期:機器人會從這天起才開始為這位客戶建單。

### ⏸️ 某客戶請假 / 暫停(例如歇業、店休一段時間)
- 後台「客人設定紀錄」→ 找到該客戶 → 按「**暫停**」
- 暫停中的客戶,機器人**不會**幫他建單;要恢復按「**啟用**」即可。

### 🗑️ 刪除客戶(不再是固定客戶)
- 後台「客人設定紀錄」→ **勾選**要刪的(可多選)→ 按「**刪除選取**」→ 確認

### 📋 查看每天的建單結果
- 後台「**執行記錄**」分頁
- 每天每一位都會有一筆:**成功** 或 **失敗(缺漏)**
- 上方數字卡:今天要排 / 今日成功 / 今日缺漏

### 🔧 某筆「缺漏」怎麼辦
1. 到後台「執行記錄」看**缺漏原因**
2. 人工登入 GoodMaji,在「一般代取」**手動補建那一筆**
3. (常見原因:客戶名稱在 GoodMaji 查不到、當天 GoodMaji 臨時異常等)

## 三、自動執行說明

- **時間**:每天早上 **08:00**(台灣時間),主機自動執行,不需開電腦、不需人工。
- **對象**:所有「啟用中」且「今天是其取件日」且「已過生效日」的客戶。
- **結果**:寫入後台「執行記錄」;成功的會在 GoodMaji「一般代取」出現(取件人=API)。
- 主機**重開機也會自動恢復**執行(已設定開機自動啟動)。

---

## 四、常見狀況

| 狀況 | 處理方式 |
|---|---|
| 今天某客戶沒建到 | 後台「執行記錄」看原因 → 人工到 GoodMaji 補該筆 |
| 想暫時停掉某客戶 | 後台「暫停」,要時再「啟用」 |
| 前台/後台打不開 | 主機或網路可能異常,請找維護者(見第五節重啟) |
| GoodMaji 改版後大量缺漏 | 可能欄位位置變了,請找維護者調整(見第五節) |

## 五、維護者技術備註

> 這一節給負責維護的人;一般操作者可略過。

### 主機與登入
- 主機:Vultr,`ssh root@202.182.99.181`
- 專案目錄:`/root/fixed-pickup-robot`
- 機密設定:`/root/fixed-pickup-robot/.env`(GoodMaji 帳密/編號、後台密碼;**切勿上傳 Git**)

### 更新程式
1. 改好的檔案上傳到 GitHub repo(Add file → Upload files)
2. 主機:`cd ~/fixed-pickup-robot && git pull`
3. 若改到前台/後台網頁:`pm2 restart pickup-form`

### 常用指令(在 `~/fixed-pickup-robot` 下)
| 指令 | 用途 |
|---|---|
| `DRY_RUN=1 node src/run.js` | 只列出「今天會建哪些人」,不開瀏覽器、不建單(安全檢查) |
| `node src/run.js` | 立即手動執行一次正式建單 |
| `npm run testfill` | 安全測試:填一筆但**不儲存**,截圖到 `logs/capture/5-filled.png` |
| `npm run testsave` | 建一筆真的 + 反查驗證(測試資料記得刪) |
| `npm run capture` | 擷取 GoodMaji 頁面(登入頁/代收頁)供校準選擇器 |
| `pm2 status` / `pm2 restart pickup-form` / `pm2 logs pickup-form` | 前台/後台服務狀態、重啟、看日誌 |
| `crontab -l` | 查看每日排程 |

### 檔案位置
| 內容 | 路徑 |
|---|---|
| 客戶資料 | `data/customers.json` |
| 執行記錄 | `data/logs.json` |
| 每日排程日誌 | `logs/cron.log` |
| 失敗截圖 | `logs/screenshots/` |
| 診斷/存證截圖 | `logs/capture/`(含建單後的 `6-saved.png`) |

### GoodMaji 改版時
- 所有頁面「選擇器」集中在 `src/robot/selectors.js`。
- 若欄位/按鈕位置改變,先跑 `npm run capture` 取得最新頁面原始碼,再對照調整 `selectors.js`。
- 登入為三欄:編號(`#number`)、帳號(`#account`)、密碼(`#password`)、登入鈕(`#SignIn`)。
- 一般代取內層頁:`collection.aspx?method=get`;新增鈕 `#linkAdd`(postback);儲存鈕 `#btnSave`;
  各欄位 id 為 `rp1_<欄位>_<列索引>`。

### 排程
- 每天 08:00(台灣時間,主機時區已設 `Asia/Taipei`)執行:
  ```
  0 8 * * * cd /root/fixed-pickup-robot && /usr/bin/node src/run.js >> /root/fixed-pickup-robot/logs/cron.log 2>&1
  ```
