# 小樹苗成長日記

同仁登入後留言、主管之後可回覆的留言板，附帶「6 個月 × 6 種造型」的每日成長小樹苗。

## 檔案說明

- `team-board-mobile.html` — 手機版介面
- `team-board-desktop.html` — 電腦版介面（側邊欄 + 多欄留言牆）
- `Code.gs` — Google Apps Script 後端程式碼

兩個 html 檔案共用同一個 Google 試算表當資料庫，開起來都是同仁登入版本。

## 設定步驟

1. 開一份新的 **Google 試算表**，建立兩個工作表(分頁)：
   - **留言板**，第一列標題依序填：
     `id / 姓名 / 日期 / 內容 / 建立時間 / 回覆 / 回覆時間`
   - **帳號**，第一列標題填：`姓名 / 密碼`，下面每一列填一位同仁的姓名和密碼

2. 上方選單「擴充功能」→「Apps Script」，把 `Code.gs` 的內容整個貼進去（覆蓋原本的 Code.gs）

3. 「部署」→「新增部署作業」→ 類型選「網頁應用程式」
   - 執行身分：**我**
   - 具有存取權的使用者：**所有人**

4. 部署完成會拿到一組網址（結尾是 `/exec`），複製起來

5. 打開 `team-board-mobile.html` 和 `team-board-desktop.html`，找到這一行，把網址貼進單引號中間（兩個檔案都要改）：
   ```js
   const API_URL = 'PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE';
   ```

## 功能重點

- 同仁需要姓名 + 密碼登入，登入後只看得到自己的留言與主管的回覆(唯讀)
- 留言時可以選日期(預設今天)
- 「小樹苗的話」是同仁寫的內容，「大樹的叮嚀」是主管的回覆
- 首頁有 6 個月的小樹苗成長排，起點是每個人**第一次留言的那天**，之後每天自動長大一點(不強迫留言)，6 個月各是不同造型：
  嫩芽小樹 → 竹之子 → 小向日葵 → 幸運草叢 → 櫻花小徑 → 豐收果樹
- 登入畫面有「🧪 先不接帳密，直接看介面」的測試模式按鈕，方便先操作介面，不會真的寫進試算表

## 之後可以擴充

主管專用的回覆介面目前還沒做，之後可以另外做一個頁面，呼叫 `Code.gs` 裡已經寫好的 `reply` 這個 action 就可以，不需要改這支後端程式碼。
